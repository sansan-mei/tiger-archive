# TIGER — FIELD TRIAL

三层战场的坦克自由混战原型。支持本地训练（1 名玩家 + 7 AI）与 WebSocket 房间对战（2–8 人），可使用现有 Redis 保存恢复检查点。

当前协议 **v8**，八个内容插件（原六个 **2.1.0**，人类／火箭筒 **1.0.0**），Redis 默认前缀 `tiger:rooms:v8`。最近一次代码验证 **85/85 测试通过**；异机联机、真实 Redis 和 Docker 运行仍待验收。

## 启动与操作

通过 Node 或 Docker 服务网址打开页面，选择车体和武器，进入本地训练或创建/加入多人房间。Three.js 0.158.0 随服务提供，无需访问外部 CDN。部署步骤与 Redis 配置见 [DEPLOY.md](DEPLOY.md)。

| 操作 | 控制 |
| --- | --- |
| 前进、倒车、车体转向 | WASD / 方向键；人类为相对镜头的前后与侧移 |
| 炮塔瞄准 | 点击战场锁定鼠标，可连续 360° 旋转；上下绕车体固定点俯仰，炮塔朝中心准星瞄准 |
| 开火 | 左键 / F |
| 激光蓄力 | 按住开火；松开提前发射，蓄满自动发射一次 |
| 刹车 | 空格 |
| 机甲技能 | Shift；按住不会反复触发 |
| 上下楼 | 直接驶入绿色标记的宽斜坡，无需交互键 |
| 暂停 / 继续 | Esc 释放鼠标并暂停操作；P 切换暂停/继续（联机时仍可受击） |
| 镜头距离 | 滚轮调整车后追尾距离；鼠标可独立转动镜头，WASD 控制车体 |
| 手机 | 方向按钮驾驶、拖动画面瞄准、开火与技能按钮；上下坡直接驾驶 |

当前规则为最多 8 车自由混战：5 分钟或先到 15 次击毁结束。时间到按击毁数、较少死亡数排名，两项相同则平局。死亡后 4 秒自动复活，优先选择离敌人较远的空闲出生点；全部被占用则等待。复活保护 2 秒，开炮立即解除。退出或超过重连期限的玩家不再复活。

地图增加出生点遮挡、侧翼掩体和顶层低墙射击位，两侧坡道支持迂回。绿色维修包恢复 40 装甲，金色加速包提供 6 秒极速 +35%，均在拾取 20 秒后刷新；满血不消耗维修包，AI 也可争夺补给。HUD 显示实时计分、比赛倒计时、受击方向、命中伤害和补给状态；死亡时跟随击毁者的实时视角（不是历史回放），结算列出全部玩家成绩。发动机、附近炮声、命中和补给音效在点击进入后启用。

## 自由组合：4 种单位 × 4 种武器

| 机甲 | 装甲 | 基础护盾 | Shift 技能 |
|---|---:|---:|---|
| 游隼 / 轻型 | 140 | 60 | 0.5 秒冲刺，约 13 米，8 秒冷却；可倒向冲刺及开火，受墙和坡道碰撞限制 |
| 先锋 / 中型 | 210 | 90 | 60 临时护盾，4 秒有效，12 秒冷却 |
| 堡垒 / 重型 | 280 | 120 | 部署 5 秒，跟随炮塔的正面 120° 减伤 70%，移动速度降至 35%，14 秒冷却 |
| 人类 / 火箭兵 | 80 | 0 | 0.25 秒闪避，4 秒冷却，无无敌；可侧移，共用斜坡 |

标准炮 35 伤害 / 1.2 秒装填；快速炮 9 伤害 / 0.3 秒装填；激光满蓄力 100 伤害 / 1.5 秒蓄力 + 2.4 秒装填。全部机甲与武器仍可自由搭配。技能按 Shift 或触屏技能按钮触发，持续按住不会反复激活。

伤害依次消耗临时屏障、基础护盾、装甲。停止开火且不受伤 5 秒后，基础护盾以 6 秒回满的速率恢复；装甲不自动恢复，维修包恢复 40 装甲。复活恢复基础护盾并清空技能效果。激光蓄力有逐渐增强的红色预警线、发光与提示音。三种机甲保留履带模型，人类使用小体积人形模型和步行动画。

以满装甲、满基础护盾、不使用技能或补给、连续命中且未触发护盾恢复为基准：

| 武器 | 单发伤害 | 轻型击毁命中数 | 中型击毁命中数 | 重型击毁命中数 |
|---|---:|---:|---:|---:|
| 满蓄力激光 | 100 | 2 | 3 | 4 |
| 标准炮 | 35 | 6 | 9 | 12 |
| 快速炮 | 9 | 23 | 34 | 45 |

激光有 1.5 秒蓄力和明显预警，标准炮便于单发换掩体，快速炮适合持续追踪压制。部分蓄力、临时屏障、正面减伤、脱战恢复和补给会改变实际击毁命中数。此表已通过真实射击及命中模拟测试，不再以旧版 10～15 秒生存目标调参。

最高前进速度：游隼 14 m/s、先锋 11 m/s、堡垒 8 m/s、人类 9 m/s；加速补给和技能按各自规则调整速度。

## 人类与火箭筒

人类 80 血，无基础护盾，碰撞半径 0.7 米；WASD 相对镜头前后/侧移，斜向移动不会提高速度。Shift 短距闪避仍受墙和坡道限制，也仍可被命中。首版无跳跃或攀爬。

火箭筒装填 2.5 秒，弹速 38 m/s：直接命中先造成 20 伤害，再对同一存活目标追加满额 80 爆炸伤害，总计最高 100。周围单位按爆点到简化碰撞体的距离，在 6 米范围内线性衰减；墙、楼板和坡面阻挡爆炸，其他单位不作为爆炸掩体。近距离会自伤，自杀不增加击毁数。

满血人类被满蓄力激光或火箭直击会一击击毁，标准炮需 3 次命中、快速炮需 9 次命中（无技能、补给与保护）。火箭直击对满血满盾轻/中/重机甲分别需 2/3/4 次命中。所有 16 种搭配可选；本地 AI 阵容也包含人类与火箭筒。

## 三层与直坡驾驶

- 三层高度分别为 0、8、16 米。每层之间设东西两条宽 12 米、水平长 28 米的直坡，坡度约 16°。
- 直接驾驶上下坡；可以停车、倒车、转向、瞄准、蓄力和开火。没有自动切层、操作锁定或无敌。
- 车身随坡面倾斜，炮塔瞄准保持世界方向；镜头跟随连续高度，并检查后方掩体与楼板。
- 上层楼板有实际开口；坡面与边缘护栏可挡弹丸和激光。坡上车辆可以被命中。
- 坡道两侧限制车辆驶出，防止从楼板开口侧面进入或掉落。首版没有自由坠落、侧翻和独立悬挂。
- AI 沿坡驾驶跨层追击；服务端计算 rampId、rampDir 与高度，客户端插值显示。

## 联机测试与异常处理

创建房间 → 分享房间码 → 所有人准备 → 房主开局，至少需要两个客户端。本地 AI 训练没有经过真实 WebSocket，不能代替这一步。

- 服务器计算移动、命中、技能和结算；按连接绑定实体，限制输入参数、序号、时间范围和发送频率。
- 技能和开火的短按不会因同一 tick 内按下/松开而被合并掉。
- 前台对局超过 1.5 秒没有更新的权威 tick 时暂停输入并提示；超过 5 秒会尝试重连。短暂停更恢复后点击继续，重连首帧会清空旧按键。
- 断线保留席位 30 秒，车辆仍可被攻击；超时或主动退出不再复活。房主离线移交管理权。
- 当前仍下发全部敌人位置，没有可见性过滤、按 IP 防刷、本机预测和延迟补偿，适合先做小范围联机内测。

代码更新后重启 Node 服务并刷新所有客户端；Docker 部署需更新镜像。新增人类与火箭筒后协议升级为 v8，显式 Redis 前缀应改为 tiger:rooms:v8，旧版本检查点不兼容。部署与验收步骤见 [DEPLOY.md](DEPLOY.md)，消息格式见 [MULTIPLAYER.md](MULTIPLAYER.md)。
