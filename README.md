# TIGER — FIELD TRIAL

三层战场的坦克自由混战原型。支持本地训练（1 名玩家 + 7 AI）与 WebSocket 房间对战（2–8 人），可使用现有 Redis 保存恢复检查点。

## 启动与操作

通过 Docker 服务网址打开页面，选择车体和武器，进入本地训练或创建/加入多人房间。Three.js 0.158.0 随镜像提供，无需访问外部 CDN。部署步骤与 Redis 配置见 [DEPLOY.md](DEPLOY.md)。

| 操作 | 控制 |
| --- | --- |
| 前进、倒车、车体转向 | WASD / 方向键 |
| 炮塔瞄准 | 点击战场锁定鼠标，可连续 360° 旋转；上下绕车体固定点俯仰，炮塔朝中心准星瞄准 |
| 开火 | 左键 / F |
| 激光蓄力 | 按住开火；松开提前发射，蓄满自动发射一次 |
| 刹车 | 空格 |
| 上下楼 | 直接驶入绿色标记的宽斜坡，无需交互键 |
| 暂停 / 继续 | Esc 释放鼠标并暂停操作；P 切换暂停/继续（联机时仍可受击） |
| 镜头距离 | 滚轮调整车后追尾距离；鼠标可独立转动镜头，WASD 控制车体 |
| 手机 | 方向按钮驾驶、拖动画面瞄准、开火与上下楼按钮 |

当前规则为最多 8 车自由混战，最后存活者获胜；联机一局 15 分钟超时平局。被击毁后可观战或重新选择配置开局，没有局内自动复活。

## 自由组合：3 种车体 × 3 种武器

| 车体 | 装甲 | 最高前进速度 | 特点 |
| --- | ---: | ---: | --- |
| 轻坦 | 90 | 14 m/s | 加速快、转向快、体积小 |
| 中坦 | 130 | 11 m/s | 均衡 |
| 重坦 | 190 | 8 m/s | 防护高、转向慢、体积大 |

| 武器 | 伤害 | 装填 / 蓄力 | 行为 |
| --- | ---: | --- | --- |
| 标准炮 | 36 | 装填 1.15 秒 | 按住连续开火 |
| 快速炮 | 10 | 装填约 0.23 秒 | 高射速弹丸 |
| 蓄力激光炮 | 最高 92 | 最低蓄力 0.3 秒，蓄满 1.5 秒；装填 2.4 秒 | 瞬时射线，按蓄力比例决定伤害 |

数值是可调整的游戏初始参数，不对应现实车辆性能。所有车体均可搭配全部武器。不同配置同时出现在同一局中，并通过统一规则计算移动、装填、命中和伤害。

## 三层与直坡驾驶

- 三层高度分别为 0、8、16 米。每层之间设东西两条宽 12 米、水平长 28 米的直坡，坡度约 16°。
- 直接驾驶上下坡；可以停车、倒车、转向、瞄准、蓄力和开火。没有自动切层、操作锁定或无敌。
- 车身随坡面倾斜，炮塔瞄准保持世界方向；镜头跟随连续高度，并检查后方掩体与楼板。
- 上层楼板有实际开口；坡面与边缘护栏可挡弹丸和激光。坡上车辆可以被命中。
- 坡道两侧限制车辆驶出，防止从楼板开口侧面进入或掉落。首版没有自由坠落、侧翻和独立悬挂。
- AI 沿坡驾驶跨层追击；服务端计算 rampId、rampDir 与高度，客户端插值显示。

## 测试

在项目目录运行：

    node --test tests/*.test.cjs

规则与传输模拟测试无需浏览器或服务。浏览器工具无法访问本地文件，真实浏览器中的视觉、触屏体验及帧率仍需单独验收。未运行构建、打包或开发服务。

## 插件化版本

车库自动读取车体和武器目录，六个内置插件独立维护参数与外观。核心统一执行射击和坡面碰撞；协议 v4 核对插件版本及参数。扩展方式见 [PLUGINS.md](PLUGINS.md)，联机选型建议见 [NETWORK-CHOICE.md](NETWORK-CHOICE.md)。

## 联机与部署文件

- server.js：同源 HTTP / WebSocket、健康检查与服务生命周期。
- room-server.js：创建、加入、准备、开局、重连、房主移交和检查点恢复。
- network-session.js：浏览器真实 WebSocket 适配器。
- redis-store.js：可选 Redis 检查点与独占租约。
- Dockerfile / compose.yaml / .env.example：镜像和现有 Redis 的配置入口。
- [DEPLOY.md](DEPLOY.md)：Docker、Redis 和反向代理部署说明。
